Operational queue

A clearer dashboard for finding agents that need you, seeing active work, and reading the latest result without losing context.

PROPOSED DIRECTION
agent-wrangler · dashboard

Interaction

Use ↑/↓ or j/k to select. Press Space to toggle a preview. Click rows and disclosure markers too.

Responsive behavior

CTX, MODEL, BRANCH, PANE, then TAB drop as space contracts. STATUS and AGENT remain tightly paired at every width.

Visual channels

Group labels explain sorting, status color shows state, and the cyan gutter shows location. No duplicate state marker is needed.
